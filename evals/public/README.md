## 许可证：RGB 是 CC BY-NC-SA 4.0

三个字要记住：**NC（非商业）**。

- 评测、研究、写进简历、面试时讲——都可以
- **不要打包进交付给客户的产物里**
- SA（相同方式共享）意味着基于它改出来的数据要以同协议发布

这条别当形式主义：用公开数据集做产品，许可证是第一批会被问的问题。

## `rgb/` 目录

官方实现原样保留（16 个文件，一行未改），`data/` 不进 git。

```bash
# 已经在本地；换台机器时这样取：
git clone --depth 1 https://github.com/chen700564/RGB
```

数据是 JSONL，每行一条：

```json
{"id": 0, "query": "印控克什米尔地区寺庙踩踏事故死亡人数",
 "answer": ["12人"], "positive": ["6 段相关文档"], "negative": ["34 段无关文档"]}
```

- **负拒绝**的用法：给 6 段 positive 里**不含答案**的那些（或全给 negative），看模型是否拒答。
  这一条直接对应 REQ-09。
- 官方实现 `reject_evalue.py` 是直接调 OpenAI completions 端点（`--url` / `--apikey`），
  让模型自己在上下文里判断——**不是**我们产品"检索 → 显式判定 → 生成"的形态。
  所以不能照跑，得改造成喂我们的判定层。

## 接入要做的三件事（都还没做）

1. 把 `zh.json` 的段落索引进**独立库**，不能污染 `fixtures/agentworkbench.db`
2. 只取负拒绝子集：构造"上下文里没有答案"的输入，跑我们的判定层，报**正确拒答率**与**误拒率**（两个数必须分开，混成一个就没有分母）
3. 结果写进 `baseline.json` 的 `public.rgb` 段，和自建集并列展示

**顺序约束**：切块器一换，块边界全变，自建集的 `(file, seq)` 也要重标。
公开基准和自建集必须绑同一个切块版本，否则两组数不可比——这条比"尽快跑出数"重要。
